Login & Navigation
Access the system with your credentials and understand the top navigation.
Steps
1
Go to the app URL and enter your username and password.
2
After login, you land on the Job Orders dashboard.
3
Use the top nav to switch between Dashboard, My Work Orders, and Admin (if admin).
4
Click the a360 logo at any time to return to the dashboard.
Roles
Admin — can create Job Orders, Work Orders, manage customers, users, and send reports.
User — can start, pause, resume, and finish assigned Work Orders from My Work.
An active timer shows in the top bar when a work order is running.

03
Admin Only
Creating a Job Order
Admins create Job Orders and define the initial scope of work inline.
Steps
1
Click the + New Job Order button on the dashboard.
2
Fill in: Title, Customer, Description, and optionally assign to a user.
3
Click "+ Add Work Order" at the bottom to add task descriptions inline.
4
Click Create Job Order — the JO and all Work Orders are created automatically.
Work Orders are created as Open / Pending — no user assigned yet. Users claim them by clicking Start.
Fields
Title — short name for the job (required)
Customer — linked customer name for report emails
Description — optional context for the job
Assigned To — leave as Open if no lead yet
Work Orders — add task descriptions; estimate set later by worker

Estimate Time
Set directly on the work order card using the hr + min inline inputs.
Auto-saves when you click away (no save button needed).
Set by the worker, not the admin at creation.
Tested Status
● Not Tested ● Testing ● Pass ● Needs Fix
Click the pill on the card to change tested status — it auto-saves instantly.
Only Admins can delete a Work Order (trash icon on each card). This action cannot be undone.
05
Users (Admin sees all)
My Work Orders
Your personal dashboard showing only your assigned tasks, with full controls.
How to use
1
Click "My Work Orders" in the top navigation bar.
2
Switch between All My Work, In Progress, and Completed tabs.
3
Use the search bar, Job Order filter, or date picker to narrow down tasks.
4
Use Pause / Resume / Finish action buttons directly in the table — no need to open a modal.
5
Open work orders (unassigned) appear with a Start button — click it to claim and begin.
Table Columns
IDWork order reference number (WIP-XXXX)
Description of the task
Linked Job Order name
Est. Time set by worker
Time Taken (live for active tasks)
Tested status badge
Assigned To / Open badge
Action buttons (Start / Pause / Finish)
Visibility Rules
Users see their own assigned tasks + all Open work orders
Admins see all 160+ work orders across all users
If you're Tagged as a collaborator, the WO also appears in your list
06
Admin
Progress Reports & Sign-Off
Send email reports to customers and team members from inside a Job Order.
How to send a report
1
Open a Job Order from the dashboard.
2
Scroll to the bottom and click the Send Report button in the footer.
3
The system automatically sends to: Customer emails + all workers on the job + you (the sender).
Progress Report
Sent when some work orders are still in progress
Shows: ID, Description, Est. Time, Time Taken, Tested, Status, Assigned To
Includes Total Time Worked at the bottom
Job Sign-Off Email
Triggered automatically when ALL work orders are completed
Title changes to "Job Sign-Off" — signals project completion
Same recipients: customer + team + sender
The system detects completion automatically — you just click the same Send Report button.
07
Admin Only
Admin Panel
Manage users, customers, and view job order summaries and analytics.
User Management
1
Click Admin in the top nav to open the Admin panel.
2
Use the Users tab to register new accounts with name, username, password, and role.
3
Set a color code per user — shown as their avatar color across the app.
4
Assign roles: Admin or User.
Customer Management
1
Switch to the Customers tab in the Admin panel.
2
Add customers with a name and one or more email addresses.
3
Use the pencil icon to edit an existing customer's name or emails.
4
Customer emails are used automatically when sending progress reports.
Job Summaries Tab
Shows a flat list of all job orders with total time worked, work order count, and status.
Each job has a print/PDF button to export a brief summary.
Use the Daily Report button to email each team member their daily time log.
